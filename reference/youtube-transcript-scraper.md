# YouTube Transcript Scraper: Channels, Playlists & Search

`wulfcare/youtube-transcript-scraper`: Get YouTube transcripts (captions and subtitles) as plain text, timestamped segments or SRT for videos, Shorts, whole channels, playlists and searches. Pick the language, fall back to auto-generated captions, and get title, channel, publish date, views and duration with each one.

**Use it for:**
- transcripts / captions / subtitles of YouTube videos as text, timestamped segments or SRT
- transcripts of every video in a channel, playlist or search
- replacement for youtube-transcript-api when it raises RequestBlocked / IpBlocked

- Store page: https://apify.com/wulfcare/youtube-transcript-scraper
- OpenAPI spec: https://api.apify.com/v2/acts/wulfcare~youtube-transcript-scraper/builds/default/openapi.json
- MCP: `https://mcp.apify.com?tools=wulfcare/youtube-transcript-scraper`

**Price:**
- $0.003 per transcript (transcript): The transcript of one video (text, timestamped segments and optional SRT) with its title, channel, publish date and other details. Videos without captions, unavailable videos, bad inputs and failed requests are never charged.

## Call it

```bash
curl -X POST "https://api.apify.com/v2/acts/wulfcare~youtube-transcript-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"urls": ["https://www.youtube.com/watch?v=UF8uR6Z6KLc"], "languages": ["en"]}'
```

```python
from apify_client import ApifyClient
client = ApifyClient(APIFY_TOKEN)
run = client.actor("wulfcare/youtube-transcript-scraper").call(run_input={"urls": ["https://www.youtube.com/watch?v=UF8uR6Z6KLc"], "languages": ["en"]})
dataset_id = run["defaultDatasetId"] if isinstance(run, dict) else run.default_dataset_id  # apify-client 1-2 vs 3+
items = list(client.dataset(dataset_id).iterate_items())
```

## Input

| Field | Type | Required | Default | Allowed values | Description |
|---|---|---|---|---|---|
| `urls` | array |  |  |  | Videos, channels or playlists: Any mix of video URLs (watch, youtu.be, Shorts, live, embed), 11-character video ids, channel URLs (@handle, /channel/UC..., /c/..., /user/...) and playlist URLs. Channels and playlists are expanded into their videos, newest first, up to the limit below. |
| `searchQueries` | array |  |  |  | YouTube searches: Optional. Transcripts of the videos YouTube lists for each search term (videos only, YouTube's relevance order). |
| `maxVideosPerSource` | integer |  | 20 | 0– | Max videos per channel, playlist or search: 0 = all of them. Single video URLs are always fetched. |
| `channelTabs` | array |  | ["videos"] |  | Channel tabs: Which of a channel's tabs to take videos from. Each tab counts as its own source for the limit above. |
| `languages` | array |  | ["en"] |  | Transcript language: Language codes in order of preference (en, es, pt-BR, ja...). "en" also matches en-US and en-GB. Captions uploaded by the creator are used before auto-generated ones in the same language. Leave empty to always get the video's original (spoken) language. |
| `ifLanguageMissing` | string |  | "original" | `original` (Use the video's original language), `skip` (Skip the video (free error row)) | If a video has none of these languages: Every row says which language it's in (language, isAutoGenerated) and lists all the video's caption languages (availableLanguages). |
| `includeAutoGenerated` | boolean |  | true |  | Use auto-generated captions: Most videos only have YouTube's automatic (speech recognition) captions. Turn off to accept only captions made by a person. |
| `includeSegments` | boolean |  | true |  | Timestamped segments: segments: [{start, duration, text}] in seconds, as shown on screen. The full transcript is always in text. |
| `includeSrt` | boolean |  | false |  | SRT subtitles: Adds the transcript as an .srt subtitle file (srt field), ready for video editors and players. |
| `includePublishDate` | boolean |  | true |  | Publish date and category: publishedAt and category, from one extra request per video. Off makes big runs about twice as fast: YouTube limits how many videos one IP address may ask for per minute. |
| `includeDescription` | boolean |  | true |  | Video description: The full description text. Title, channel, duration, views, keywords and thumbnail are always included. |
| `maxConcurrency` | integer |  | 5 | 1–20 | Videos at a time: Videos processed at once. YouTube lets each IP address fetch roughly 40-75 videos a minute, so a bigger proxy pool speeds up big runs more than this does. |
