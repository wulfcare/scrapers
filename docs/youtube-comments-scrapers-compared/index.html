How to choose

  • You want the safest choice: streamers has by far the most users and reviews. It costs eight times the cheapest options on the free plan, and still 50% more on Diamond ($0.30 against $0.20).
  • You're on Apify's free plan: ours and supreme_coder tie at $0.25 per 1,000. Ours has no per-run fee, which only matters if you make a lot of small runs.
  • You're on a Bronze or Silver plan: supreme_coder is slightly cheaper per comment ($0.20, against our $0.225 and $0.2125).
  • You run high volume: test your real workload, because speed and failure rates matter more than a few cents, and this page doesn't measure those for the others.

What ours does

  • Works from video and Shorts URLs, video IDs, channels, playlists, search URLs and plain search terms
  • Returns replies on request, each right after its comment
  • Sorts by top or newest, with an optional date cut-off
  • Includes likes, reply count, creator heart, pinned and edited flags, and the video's exact comment total
  • Uses the same input and output field names as streamers, so switching means changing the Actor id
  • Doesn't charge for errors or videos with comments turned off

In our tests, a default run of 100 comments took 3–9 seconds, and 2,000 comments with replies took 54 seconds. We haven't benchmarked the others, so this isn't a speed comparison.
