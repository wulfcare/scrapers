# YouTube transcript API that doesn't get IP-blocked

**Already using an Apify transcript Actor?** Jump to [Switching from another Apify transcript Actor](#switching-from-another-apify-transcript-actor): same input, same output, change one line, pay $0.003 per transcript.

Using [youtube-transcript-api](https://github.com/jdepoix/youtube-transcript-api) from a server or in bulk, you'll eventually hit:

```
youtube_transcript_api._errors.RequestBlocked: Could not retrieve a transcript for the video ...
YouTube is blocking requests from your IP. This usually is due to one of the following reasons:
- You have done too many requests and your IP has been blocked by YouTube
- You are doing requests from an IP belonging to a cloud provider (like AWS, Google Cloud Platform, Azure, etc.)
```

(or its subclass `IpBlocked`). YouTube blocks cloud IPs and any IP that asks for many transcripts.

The [YouTube Transcript Scraper on Apify](https://apify.com/wulfcare/youtube-transcript-scraper) fetches transcripts through Apify's proxies and handles blocks and retries for you. It also takes **whole channels, playlists and searches**, not just single video IDs.

```python
from wulfcare import run   # ../wulfcare.py

rows = run("wulfcare/youtube-transcript-scraper", {
    "urls": ["https://www.youtube.com/watch?v=UF8uR6Z6KLc", "https://www.youtube.com/@3blue1brown"],
    "maxVideosPerSource": 20,
    "languages": ["en"],          # falls back to auto-generated captions
    "includeSegments": True,      # timestamped segments
    "includeSrt": False,          # set True for an SRT file per video
})
for r in rows:
    print(r["title"], r["wordCount"], r["text"][:200])
```

Each row: `videoId`, `title`, `channelName`, `publishedAt`, `durationSeconds`, `viewCount`, `language`, `isAutoGenerated`, `text`, `segments`, `srt`, `availableLanguages` and more.

Search instead of URLs: `{"searchQueries": ["how transformers work"], "maxVideosPerSource": 50}`.

**Cost:** $3 per 1,000 transcripts. Videos without captions, unavailable videos and bad inputs are free. Apify's free plan includes $5/month.

```bash

  -H "Content-Type: application/json" -d '{"urls": ["https://www.youtube.com/watch?v=UF8uR6Z6KLc"]}'
```

## Switching from another Apify transcript Actor

`wulfcare/youtube-transcript-scraper` accepts the two input styles most YouTube transcript / subtitle Actors use and returns their field names, so **only the Actor id changes** in your code.

**Style 1: `startUrls` + `timestamps`** (e.g. "YouTube Subtitle Scraper AI")

```python
run = client.actor("wulfcare/youtube-transcript-scraper").call(run_input={
    "startUrls": ["https://www.youtube.com/watch?v=UF8uR6Z6KLc"],
    "timestamps": True,
})
# item: videoUrl, videoId, videoTitle, channelName, views, language, text
# text = "[00:00:07.470] This program is brought to you by Stanford University.\n[00:00:10.470] ..."
```

**Style 2: `videoUrl` + `targetLanguage`** (e.g. "YouTube Transcript Scraper" by pintostudio)

```python
run = client.actor("wulfcare/youtube-transcript-scraper").call(run_input={
    "videoUrl": "https://www.youtube.com/watch?v=UF8uR6Z6KLc",
    "targetLanguage": "en",
})
# item["data"] = [{"start": "7.470", "dur": "2.899", "text": "This program is brought to you by Stanford University."}, ...]
```
